# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Marketing website for ApproLogic's product "Service Pacemaker" (after-sales portal for machine builders). All site content, code comments and the README are in German; keep new content and comments in German.

## Commands

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to ./out (this is what gets deployed)
```

There is no lint script and no test suite. `npm run build` is the check: it type-checks and renders every page.

## Architecture

Content-driven static site (Next.js App Router, `output: "export"`, `trailingSlash: true`, see [next.config.ts](next.config.ts)). There is no server at runtime; the contents of `out/` are copied to any plain web server.

- **One catch-all route renders every page**: [app/[[...slug]]/page.tsx](app/[[...slug]]/page.tsx). `generateStaticParams` walks `content/pages/`, so a new `.md` file automatically becomes a page. The page template (breadcrumbs, hero with eyebrow/title/lead, body, prev/next pager) lives here.
- **File path = URL**: `content/pages/funktionen/wartung.md` → `/funktionen/wartung/`; `index.md` → `/`. Loading and the frontmatter type (`PageMeta`) are in [lib/content.ts](lib/content.ts).
- **Navigation is not derived from files**: main nav, submenus and footer columns are hand-maintained in [content/site.ts](content/site.ts) (also company address/phone/email and the global CTA). Breadcrumbs, `prev`/`next` and `section` (active nav item) are set manually in each page's frontmatter. Adding, renaming or moving a page therefore means updating the `.md` file, `content/site.ts`, and the `prev`/`next`/breadcrumbs of neighboring pages.
- **Custom Markdown blocks**: [components/Markdown.tsx](components/Markdown.tsx) intercepts fenced code blocks by language — `tiles`, `numbers`, `cta`, `image` (placeholder), `video` (MP4 from `public/video/` with poster, via [components/Video.tsx](components/Video.tsx)), `form` (renders `ContactForm`). Syntax is documented in the README and the component's header comment. `<pre>` is unwrapped so these render as plain blocks; internal links (`/…`) become `next/link`. New block types are added in the `code` renderer there.
- **Site URL** for canonical links, `sitemap.xml` and `robots.txt` (generated by [app/sitemap.ts](app/sitemap.ts) and [app/robots.ts](app/robots.ts)) is `site.url` in [content/site.ts](content/site.ts). Graphics in `image` blocks open full-screen on click via [components/Zoomable.tsx](components/Zoomable.tsx) (not for the `logos` variant).
- **SEO:** each page's frontmatter has `seoTitle` (≤ ~45 chars, " | ApproLogic" is appended) and `description` (≤ ~160 chars). Open Graph, Twitter card and canonical are set in `generateMetadata` in the catch-all page; JSON-LD in [components/StructuredData.tsx](components/StructuredData.tsx); German 404 in [app/not-found.tsx](app/not-found.tsx) with its texts in `notFoundPage` in `content/site.ts`. The share image `public/vorschau.png` is exported from `assets/vorschau.svg`. Post-launch steps (redirects, Search Console) are in the README.
- **Internal links must end with `/`** (trailing slash export, no rewrites on the server).
- The contact form ([components/ContactForm.tsx](components/ContactForm.tsx)) posts JSON to `/api/kontakt`. That endpoint is not part of the Next.js build: it is a standalone, dependency-free Node service in [server/kontaktformular.mjs](server/kontaktformular.mjs) that runs on the Hetzner server behind nginx and sends via the Mailgun API (setup, local testing with `DRY_RUN=1` and `NEXT_PUBLIC_CONTACT_ENDPOINT`: [server/README.md](server/README.md)). Spam protection is a honeypot field `website`, a fill-time stamp `t` and a per-IP rate limit; keep these fields when changing the form.
- Styling is a single global stylesheet, [app/globals.css](app/globals.css) (no CSS framework). Brand colors from apprologic.de are CSS variables at the top; fonts (Work Sans, Open Sans) come via `next/font` in [app/layout.tsx](app/layout.tsx). The logo is inline SVG in [components/Logo.tsx](components/Logo.tsx) (`currentColor`). The home page gets `.page-home` for its dark hero; the paragraph right after an `image` block there is styled as a trust bar. Class names used by the components (`tiles`, `tile`, `numbers`, `next`, `btn primary`, `crumbs`, `pager`, `hero`, `lead`, …) are defined there.
